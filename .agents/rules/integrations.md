# Reglas de integraciones

- No incluir secretos, tokens ni datos personales reales.
- Implementar ARCA y Mercado Pago mediante puertos, adaptadores, idempotencia, reintentos y observabilidad.
- Registrar pendientes legales como pendientes verificables; no asumir cumplimiento.
- No implementar WhatsApp, offline completo ni clientes nativos dentro del MVP.
