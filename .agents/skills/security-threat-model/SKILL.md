# security-threat-model

## Cuándo usarla
Al incorporar autenticación, permisos, datos o integraciones.
## Entradas
Activos, actores, superficie de ataque y flujo de datos.
## Procedimiento
Identificar amenazas, controles, auditoría y riesgos residuales.
## Validaciones
No exponer secretos ni datos reales; comprobar autorización explícita.
## Salidas esperadas
Riesgos priorizados y controles verificables.
