# Glosario inicial

| Término | Definición |
| --- | --- |
| Pedido | Solicitud comercial de productos o servicio, con estados controlados. |
| Reserva | Cantidad de inventario comprometida para una demanda aún no consumida. |
| Lote | Unidad trazable de recepción o producción con vencimiento y estado. |
| Receta | Versión aprobada de ingredientes, rendimiento, merma y proceso. |
| Orden de producción | Instrucción para producir una cantidad según receta y demanda. |
| Movimiento de stock | Registro inmutable de ingreso, egreso, reserva, liberación o ajuste. |
| Producto de proveedor | Vínculo estable entre proveedor y producto que define unidad de compra, factor de conversión, mínimo, plazo y preferencia. |
| Precio de proveedor | Condición monetaria versionada por vigencia; actualizar un precio crea historia y no reescribe el pasado. |
| Orden de compra | Compromiso con un proveedor. Al aprobarse congela producto, precio, unidad y factor de cada renglón. |
| Recepción de compra | Registro idempotente de mercadería recibida, aceptada y rechazada; sólo lo aceptado incrementa stock. |
| Discrepancia de recepción | Diferencia accionable por faltante, exceso, daño, calidad o producto incorrecto. |
| Cobranza | Aplicación idempotente de un pago a una cuenta o comprobante. |
| Caja | Sesión operativa de apertura, movimientos, arqueo y cierre. |
| Alerta | Incidente accionable originado por evento y gobernado por una regla. |
